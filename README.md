# Cuaderno de Hanzi

Sesión diaria de chino mandarín para hispanohablantes: orden de trazos corregido al trazar, repaso espaciado, tonos, lecturas cortas y frases corregidas con IA. Cubre el vocabulario del HSK 1 (151 palabras, 196 caracteres).

Ábrelo en https://jhonsaavedrau-dev.github.io/cuaderno-hanzi/ y entra con un usuario y un PIN de 4 números (la cuenta se crea la primera vez). Se puede instalar en el celular o en el PC desde el menú del navegador.

Este repo contiene el sitio ya armado. Los datos de trazos vienen de [Make Me a Hanzi](https://github.com/skishore/makemeahanzi) vía [Hanzi Writer](https://hanziwriter.org) (licencia Arphic Public License); el audio está generado con voces neuronales.
